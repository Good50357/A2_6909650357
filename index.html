What I Built

เว็บไซต์นี้เป็นเว็บไซต์แบบหน้าเดียว (single-page) ที่รวบรวมข้อมูลของ 5 เกมคอมพิวเตอร์ที่สร้างรายได้สูงสุดในปี 2025 โดยแสดงอันดับ ไอคอนประจำเกม และรายได้โดยประมาณของแต่ละเกม

ส่วนประกอบสำคัญของเว็บไซต์

  • <header> และ <nav> สำหรับชื่อเว็บไซต์และเมนูเชื่อมไปยังแต่ละหัวข้อ
  • <main> และ <section> แบ่งเนื้อหาออกเป็นหมวดหมู่อย่างชัดเจน
  • รายการ (<ul> / <ol>) แสดงอันดับเกมและรายละเอียดต่าง ๆ
  • ลิงก์ (<a>) เชื่อมไปยังหน้าข้อมูลเพิ่มเติมของแต่ละเกม
  • <footer> สำหรับข้อมูลปิดท้ายหน้าเว็บ

เรื่อง Client / Server

ยังไม่เกิด client-server เพราะ เมื่อลองเปิดไฟล์ index.html เบราว์เซอร์จะเปิดไฟล์ผ่านโปรโตคอล file:// ซึ่งเป็นการอ่านไฟล์จากดิสก์ในเครื่องโดยตรง ไม่ได้ส่ง request ผ่าน network ไปหา web server เพราะไม่มีเครื่อง server ที่คอยรับ request และ response อยู่คนละเครื่องหรือคนละ process กับผู้ใช้ เบราว์เซอร์ในเครื่องทำหน้าที่เป็นทั้งผู้ขอไฟล์และผู้แสดงผลในเวลาเดียวกัน

How I Built It

พัฒนาเว็บไซต์นี้โดยเรียนรู้จากอาจารย์ในมหาวิทยาลัย ร่วมกับคลิปสอนฟรีบนยูทูป

ขั้นตอนสำคัญ

  1. ดูคลิปสอนฟรีเพื่อทำความเข้าใจโครงสร้าง HTML และหลักการเขียน CSS เบื้องต้น
  2. ฝึกทำตามไฟล์แบบฝึกหัดที่อาจารย์แปะไว้ให้
  3. ร่างโครงหน้าเว็บ เขียนเนื้อหา แล้วค่อย ๆ ใส่ style ทีละส่วน
  4. ใช้ AI เป็นเหมือนโค้ชคอยช่วยตรวจสอบโค้ด ชี้จุดผิดพลาดเล็ก ๆ น้อย ๆ และอธิบายคำสั่งที่ยังไม่เข้าใจ

Reflection

ปัญหาหรือความท้าทายที่พบ

ลืมคำสั่งบางคำสั่งว่าทำงานยังไงหรือเขียนยังไง ทำให้ได้ผลลัพธ์ไม่ตรงตามที่ต้องการ แก้ปัญหาโดย กลับไปทบทวนและค้นหาข้อมูลเพิ่มเติมจาก Google และ AI

สิ่งที่เข้าใจมากขึ้นเกี่ยวกับการพัฒนาเว็บไซต์

ทำให้คุ้นเคยกับเครื่องมือและคำสั่งต่าง ๆ มากขึ้น และเข้าใจการทำงานของโค้ดได้ดีขึ้น ทั้งเรื่องโครงสร้างของ HTML และการจัดรูปแบบด้วย CSS

สิ่งที่อยากปรับปรุงหากพัฒนาต่อ

หากได้พัฒนาเว็บไซต์นี้ต่อ อยากเพิ่มลูกเล่น สีสัน และ animation ขยับได้มากขึ้น เพราะอยากให้เว็บไซต์มีความน่าสนใจ และทำให้ผู้ใช้พึงพอใจมากขึ้น
